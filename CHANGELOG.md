# Changelog

## 1.0 — 2026-09-29

First release.

- Learning path: 18 lessons + final exam covering A–Z, 0–9 and `. , ? / =`
- First-start onboarding: experience choice, interactive key tutorial, placement test
- Practice: Listen, Send, Hear words, Send words, Weak spots, Callsigns
- Games: Morse Rush, Sound Sprint, Echo Chain
- Free Key with live decoding and playback
- Alphabet reference with pattern, pronunciation, look-alikes and mastery
- Stats: level/XP, daily goal, streak, per-sign mastery, 12 badges, records
- Paddle and straight-key keying, Farnsworth spacing, adjustable tone/speed/letter pause
- Sound, vibration and RGB LED feedback, each switchable
